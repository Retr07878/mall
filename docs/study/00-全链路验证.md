## 3. 核心链路（自己讲一遍）

```
会员登录(JWT) 
  → 加购物车(oms_cart_item)
  → 确认订单(算价/优惠券/积分)
  → 生成订单:
       ① 校验库存 hasStock
       ② 锁定库存 lockStock  → pms_sku_stock.lock_stock +1
       ③ 插入 oms_order / oms_order_item
       ④ 清空购物车
       ⑤ 发 RabbitMQ 延迟消息(30min TTL) → 死信队列 → 未支付自动取消
  → 支付回调 paySuccess:
       ① 订单 status 0→1
       ② 实际扣库存 updateSkuStock（stock-1）
       ③ lock_stock 释放
       ④ 更新优惠券/积分状态
  → 未支付取消 cancelUserOrder:
       订单 status→4，releaseSkuStockLock 释放 lock_stock
```

## 6. 本次环境问题与解决（面试可讲的小坑）

| 现象 | 原因 | 解决 |
|---|---|---|
| Docker 拉镜像超时 | registry-1.docker.io 国内不可达 | 配置 registry-mirrors（daocloud/1ms 等） |
| mall-admin 启动报 `Public Key Retrieval is not allowed` | MySQL 8 默认 caching_sha2_password + useSSL=false | JDBC URL 加 `allowPublicKeyRetrieval=true` |
| mall-portal 启动报 RabbitMQ `ACCESS_REFUSED` | 容器默认只有 guest，mall 需要用户 mall/vhost /mall | rabbitmqctl 创建用户/vhost/权限 |
| 购物车确认单 NPE（getPrice() null） | 直接调接口时购物车缺 price/productName 字段 | 按前端真实参数补全字段 |
| 生成订单报"该优惠券不可用" | `couponId:0` 被当成真实券 | 不用券时不传 couponId(null) |
