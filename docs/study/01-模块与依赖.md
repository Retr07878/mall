# mall 模块与依赖梳理（W0 产出）

> 目标：合上文档能口述每个模块的职责、依赖和启动条件。先填空，再补图。

## 1. 模块清单（把「职责」和「依赖」两列自己填完）

| 模块 | 职责 | 依赖的内部模块 | 运行时中间件 | 端口 |
|---|---|---|---|---|
| mall-common | 公共类库：统一返回体 CommonResult、全局异常处理、工具类、日志切面 WebLogAspect、Redis 封装 / | | 无| - |
| mall-mbg |MyBatis Generator 生成的数据访问层：model、mapper 接口、mapper XML、Example 条件构造器| mall-common|无 | - |
| mall-security | Spring Security 安全模块：JWT 过滤器、动态权限（DynamicAuthorizationManager）、Redis 缓存 token/资源 |mall-common | | - |
| mall-admin | 后台管理系统 API：商品/订单/会员/营销/权限等管理接口，加 Druid 监控、Swagger |mall-mbg mall-security|redis,mysql,MinIO 可选，Logstash 默认关 | 8080 |
| mall-portal |  前台商城 API：首页/搜索/购物车/下单/支付回调/会员中心；MQ 做订单超时取消|mall-mbg mall-security |MySQL、Redis、MongoDB、RabbitMQ（Logstash 默认关）| 8085 |
| mall-search | 	商品搜索 API：基于 Elasticsearch 的搜索、相关商品推荐、数据导入| mall-mbg|MySQL、Elasticsearch（Redis 仅 starter 引入未实际使用）| 8081 |
| mall-demo |示例/演示模块：各种 Spring Boot 用法示例，不参与线上部署 |mall-mbg |mysql | 8082 |

mall（聚合父工程，只做版本/依赖管理）
 ├── mall-common      （无内部依赖）
 ├── mall-mbg         → mall-common
 ├── mall-security    → mall-common
 ├── mall-admin       → mall-mbg, mall-security
 ├── mall-portal      → mall-mbg, mall-security

 └── mall-demo        → mall-mbg

## 3. 启动顺序 / 条件（自己验证后填）

- 只启动 mall-admin 需要：MySQL + Redis
- mall-portal 需要：MySQL + Redis + MongoDB + RabbitMQ
- mall-search 需要：MySQL + Elasticsearch
